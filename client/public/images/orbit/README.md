# Carousel backdrop

`kitchen-wall.webp` is the embedded `IMG_ROOM` asset extracted unchanged from the Dish Orbit Carousel supplied by the user. Its source comment identifies Unsplash photo `1653971858474-4f2dfa7f4dc1`, processed in that supplied example with the plain wall extended around it.

Source image: https://images.unsplash.com/photo-1653971858474-4f2dfa7f4dc1

Recipe photographs in the carousel use the project's existing TheMealDB images so each image matches the recipe opened by its action. The illustrative demo's fictional chef names, ratings and like counts are not used as app data.
